# Core AI Generation Service Boundary

Accepted. AI generation is a core capability split into `core/domain/ai-generation-service`, `core/application/ai-generation-service`, and `core/infra/ai-generation-service`. Core domain may contain provider-agnostic capability types and invariants such as Generation Operation, Generation Quote, staged generated artifacts, modality, provider, provider-scoped model unions, product-level generation config, and typed AI generation errors. Core application owns the `AiGenerationService` Effect port with explicit operations such as quote generation, generate text, generate images, and generate video. Quote generation accepts a validated Generation Operation and returns a credit-denominated Generation Quote without execution context. Generation execution uses modality-specific methods and receives caller-provided request/staging context for idempotency, timeout/cancellation, and artifact staging identity. Core infra owns provider routing, SDK clients, request normalization, response extraction, media normalization, object-storage staging through the generic object storage capability, timeout/cancellation handling, and provider error mapping. Image and video generation results return staged object references, not bytes or workflow Assets; text generation may return bounded inline text. Feature modules such as workflow and runtime map their own feature-owned data into core Generation Operations; core AI generation modules must not import workflow, runtime, task, credit ledger, or workflow document concepts. Credits remains separate and only applies ledger mutations in credit units.
